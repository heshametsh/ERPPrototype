# شنطة الذاكرة — لأي مشروع جديد

**إيه دي؟** نظام ذاكرة بيخلّي Claude فاهم المشروع في كل شات جديد. الشرح الكامل في `memory/HOW_THIS_WORKS.md`.

## التركيب (3 خطوات)
1. انسخ **محتوى** المجلد ده كله في جذر المشروع الجديد، ومعاه الملفات المخفية (`.claude/` و`.gitignore`).
   لو المشروع عنده `.gitignore` قبل كده، ضيف عليه السطر اللي في الملف هنا.
2. في أول شات قول: **"اقرا memory/HOW_THIS_WORKS.md واسألني أسئلة القصة واملا STORY و RULES معايا"**.
3. اعمل commit، ومن هنا النظام بيشتغل لوحده.

## الاستخدام اليومي
| امتى | تعمل إيه |
|---|---|
| أي شات جديد | ولا حاجة. Claude بيقرا الذاكرة لوحده |
| آخر مهمة | الجرس بيفكّره. ولو عايز تطلب بنفسك: `/update-memory` |
| مرة في الأسبوع | `/memory-test` في شات جديد، وقيّم إجاباته |
| Claude غلط في حاجة كانت مكتوبة | قوله "سجّلها في corrections" |

## المحتويات
```
CLAUDE.md                       المدخل: بيستدعي القصة والقواعد + إزاي يتعامل معاك ومع الذاكرة
memory/STORY.md                 قصة المشروع          (دايمة)
memory/RULES.md                 ممنوعات + فخاخ + تشغيل (دايمة)
memory/decisions.md             القرارات بالتفصيل     (وقت الحاجة)
memory/incidents.md             مشاكل اتحلّت          (وقت الحاجة)
memory/corrections.md           عدّاد: هل الذاكرة نافعة؟
memory/HOW_THIS_WORKS.md        شرح التصميم
.claude/settings.json           تشغيل الأجراس
.claude/hooks/                  الأجراس: أول الشات وآخر الرد
.claude/skills/update-memory    الأمر /update-memory
.claude/skills/memory-test      الأمر /memory-test
```

> الأجراس محتاجة `bash` و`git`. على ويندوز بيبقوا موجودين لو Git for Windows متسطّب.
