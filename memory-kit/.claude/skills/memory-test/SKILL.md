# اختبار الذاكرة

جاوب على الأسئلة دي **من ملفات memory/ و git log بس**، من غير ما تفتح الكود. كل إجابة في سطرين بالكتير، وجنبها مصدرها (الملف/القسم):

1. إيه المشروع ولمين؟
2. إيه الأجزاء الأساسية، وكل جزء فين؟
3. إحنا فين دلوقتي (من git) ورايحين على فين؟
4. إيه أهم 3 ممنوعات؟
5. لو هبني ميزة صغيرة النهارده، إيه أكتر فخ لازم آخد بالي منه؟

بعدها:
- اذكر أي **تعارض** بين الذاكرة و git، زي مرحلة مكتوبة قديمة.
- اذكر أي سؤال **ما لقيتلوش إجابة**.
- اطلب من المستخدم يقيّم كل إجابة (صح / غلط / ناقص)، واقترح التعديلات المطلوبة على الذاكرة بطريقة `/update-memory`.
