# تحديث الذاكرة

1. **راجع الشات ده:** إيه اللي اتعمل، إيه اللي اتقرر، وإيه اللي وقّعنا.
2. **فلتر كل معلومة بالأسئلة دي، ولازم تجاوب "آه" عليهم كلهم:**
   - ما تتعرفش من الكود ولا من git؟
   - اتثبتت (اختبار / لوج / قرار صريح من المستخدم)، ومش مجرد تخمين؟
   - هتفرق في شغل جاي؟
3. **حدّد مكانها:**
   | النوع | المكان |
   |---|---|
   | قرار كبير بيغيّر الاتجاه | سطر في `STORY.md` (نقط التحول) + التفاصيل في `decisions.md` |
   | قاعدة أو ممنوع من المستخدم | `RULES.md` ← الممنوعات |
   | حاجة وقّعتنا ومحتمل تتكرر | `RULES.md` ← الفخاخ (مع "إزاي تتأكد") + التفاصيل في `incidents.md` |
   | تغيير في الأجزاء أو الاتجاه | `STORY.md` |
   | معلومة بقت غلط أو بقى ليها اختبار آلي | **امسحها** |
4. **اعرض على المستخدم قبل ما تحفظ**، بالعربي وباختصار:
   ```
   هضيف:  F3 — (الفخ) — لأن (اللي حصل النهارده)
   هعدّل: STORY §4 — "رايحين على الصلاحيات" بدل "الأعمدة"
   همسح:  F1 — بقى عليه اختبار آلي
   ```
   ولو مفيش جديد قول "مفيش جديد للذاكرة" وخلاص، من غير ما تخترع.
5. **بعد الموافقة:** عدّل الملفات، وحدّث سطر "آخر مراجعة" في أي ملف لمسته، واتأكد إن السقف (STORY ≤ 120، RULES ≤ 80) لسه محترم.
