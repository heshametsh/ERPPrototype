# شكل النظام — شرح بسيط

## الصورة الكبيرة

```
  المتصفح (React + TypeScript)
        │  نفس العنوان، الدخول بالكوكي
        ▼
  ASP.NET Core API  ── موديول المنظمة (الفروع، الأقسام، المستخدمين)
        │            ── موديول أوامر العمل (الشيت والحفظ)
        │            ── (بعدين) البلدية، التنفيذ، الفحص، المستندات...
        ▼
  PostgreSQL  ── كل موديول ليه "درج" لوحده (schema): organization, work_orders, ...
```

تشبيه: النظام **مبنى واحد** فيه **أقسام**. كل قسم ليه مكتبه ودولابه (جداوله).
قسم ماياخدش ورق من دولاب قسم تاني؛ بيطلبه من الشباك الرسمي بتاعه.
ده اسمه **Modular Monolith**: سهل في التشغيل زي تطبيق واحد، ومنظم زي تطبيقات منفصلة.

## الفولدرات

```
ContractorERP/
├── backend/                       السيرفر (.NET)
│   ├── src/
│   │   ├── Host/                  التطبيق اللي بيشتغل: بيجمع الموديولات + الأمان + الإعدادات
│   │   ├── BuildingBlocks/        الحاجات المشتركة الصغيرة (الساعة، المستخدم الحالي، شكل الأخطاء)
│   │   └── Modules/
│   │       ├── Organization/      الفروع والأقسام والحسابات وتسجيل الدخول
│   │       └── WorkOrders/        أوامر العمل
│   │           ├── Domain/        قواعد البزنس (رقم 9 أرقام، المتبقي = القيمة - الجزئي...)
│   │           ├── Application/   العمليات (قراءة الشيت، الحفظ)
│   │           ├── Infrastructure/ قاعدة البيانات
│   │           └── Api/           العناوين اللي الواجهة بتكلمها
│   └── tests/
│       ├── UnitTests/             اختبارات القواعد (سريعة جدًا)
│       ├── IntegrationTests/      اختبارات على PostgreSQL حقيقي
│       └── ArchitectureTests/     يتأكد إن الموديولات مابتدخلش في بعض
├── frontend/                      الواجهة (React)
│   └── src/
│       ├── app/                   الهيكل العام: الثيم، التنقل، الشريط العلوي
│       ├── shared/                المشترك: الاتصال بالسيرفر، النصوص العربية
│       └── modules/
│           ├── auth/              شاشة الدخول
│           └── work-orders/       شاشة أوامر العمل
│               └── sheet/
│                   ├── sheetSession.ts     "عقل" الشيت: التغييرات، الحفظ الآمن (من غير أي مكتبة)
│                   └── WorkOrdersGrid.tsx  الملف الوحيد اللي يعرف مكتبة الشيت
├── deploy/                        التشغيل عند العميل (Docker + HTTPS + نسخ احتياطي)
└── docs/                          الوثائق (الخطة، القواعد، التراخيص)
```

## قواعد ثابتة (متاخدة من دروس المشروع القديم)

1. **السيرفر هو صاحب القرار.** المتصفح بيسرّع ويعرض أخطاء بدري، لكن الصلاحيات والتكرار والتعارض بيتقرروا في السيرفر وقاعدة البيانات.
2. **الحفظ = عملية واحدة.** يا كله يتحفظ يا مفيش حاجة تتحفظ.
3. **محدش يكتب فوق شغل حد.** كل صف معاه "رقم نسخة"؛ لو حد حفظ قبلك، حفظك بيترفض وتغييراتك بتفضل قدامك.
4. **مكتبة الشيت محبوسة في ملف واحد** (`WorkOrdersGrid.tsx`). قواعد الشيت في `sheetSession.ts` ومختبرة لوحدها. لو غيّرنا المكتبة، بنغيّر ملف واحد.
5. **ساعة واحدة للبزنس** (توقيت الرياض)، مش ساعة الجهاز.
6. **باسورد مؤقت = ممنوع أي شغل** لحد ما يتغير. ده متطبق على كل العناوين تلقائيًا.
7. **تحديث قاعدة البيانات خطوة نشر صريحة** (`--migrate`)، مش أوتوماتيك وقت تشغيل الموقع.
8. **كل موديول جديد** = مشروع جديد تحت `Modules/` + سطر واحد في `Host/Program.cs` + شاشاته تحت `frontend/src/modules/`.
