# تعليمات للذكاء الاصطناعي في المشروع ده

- صاحب المشروع **مصمم مش مبرمج**. كلّمه بالعامية المصرية، باختصار: إيه اللي حصل ← ليه مهم ← القرار المطلوب. من غير تفاصيل كود إلا لو لازمة لقرار.
- اقرأ `docs/PLAN.md` و `docs/ARCHITECTURE.md` و `docs/business/` قبل أي شغل كبير. قواعد البزنس في `docs/business/15_...` محسومة؛ ماتسألش فيها تاني إلا لو فيه تعارض حقيقي.
- **مجاني بس:** أي مكتبة جديدة لازم ترخيصها مجاني تجاريًا وتتسجل في `docs/LICENSES.md` قبل إضافتها. ممنوع MediatR/AutoMapper/MassTransit الجديدين.
- **الطريقة:** السلوك المطلوب ← اختبار يفشل ← كود ← الاختبار ينجح ← المستخدم يجرب ← قبول. تغيير صغير في المرة.
- **حدود ثابتة:** السيرفر صاحب القرار في الصلاحيات والتكرار والتعارض. موديول مايدخلش على جداول موديول تاني. مكتبة الشيت محبوسة في `WorkOrdersGrid.tsx`، وقواعد الشيت في `sheetSession.ts` بدون أي مكتبة.
- قبل التسليم: `dotnet build` + `dotnet test` في `backend`، و `npm run lint && npm run typecheck && npm test && npm run build` في `frontend`. كله لازم يبقى أخضر.
- لو اختبار فشل: حدد السبب الأول (كود المنتج؟ الاختبار نفسه؟ البيئة؟) قبل ما تغير أي حاجة. محاولتين فاشلتين على نفس المشكلة = وقف وتحقيق من الأساس قبل التالتة.
- ماتعملش commit أو push من غير إذن المستخدم.
