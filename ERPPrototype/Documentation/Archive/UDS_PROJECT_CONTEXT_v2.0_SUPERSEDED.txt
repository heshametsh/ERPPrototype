===========================================================
PRODUCT VISION
===========================================================

UDS ERP is a cloud-first, Microsoft-native contractor operations platform built
specifically for contractors working with Saudi Electricity Company (SEC).

The product is designed to evolve from serving a single contractor into a
commercial ERP platform capable of serving multiple contractors without major
architectural redesign.

Power Apps is the presentation layer.
Dataverse is the operational data platform and source of truth.

===========================================================
PROJECT OVERVIEW
===========================================================

This is NOT a Power Apps project.

This is a long-term Software Product.

Power Apps is only one implementation technology inside the Microsoft ecosystem.

The Microsoft ecosystem is a strategic architectural decision, not merely a
technology choice.

===========================================================
PROJECT GOAL
===========================================================

Digitize and optimize contractor operations through a Microsoft-native ERP
platform.

Replacing Excel is the first milestone—not the final objective.

===========================================================
PROJECT PHILOSOPHY
===========================================================

Business before Technology.

Architecture before Coding.

Documentation before Implementation.

Performance is a Feature.

Every feature should reduce user effort.

Documentation should reduce complexity, not create it.

===========================================================
NON-NEGOTIABLE PRINCIPLES
===========================================================

- Architecture before implementation.
- Business requirements drive architecture.
- Dataverse is the single source of truth.
- Power Apps is an implementation platform.
- Microsoft-native whenever possible.
- No undocumented shortcuts.
- Every major architectural deviation must be documented.
- User productivity is always the primary UX objective.

- Automate Repetitive Tasks
- Never ask the user for information the system already knows

===========================================================
DATA ENTRY
===========================================================

The primary experience should resemble Microsoft Excel.

Users must be able to:

- Type continuously.
- Edit any row at any time.
- Copy/Paste.
- Use keyboard navigation.
- Enter multiple Work Orders quickly.

Minimum Required Fields

- Work Order Number
- Work Type

===========================================================
COMPANY STRUCTURE
===========================================================

Company
  -> Branch
      -> Department
          -> Users
              -> Work Orders

Each user enters directly into their own workspace.

===========================================================
WORK ORDER RULES
===========================================================

Logical uniqueness:

Work Order Number + Work Type

Current Status only.

KPIs are calculated automatically.
