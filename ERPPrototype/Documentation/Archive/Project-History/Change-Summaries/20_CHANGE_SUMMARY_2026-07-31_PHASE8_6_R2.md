# 20 — Change Summary: Phase 8.6-R2 Grid Interaction Ownership

**الحالة:** Accepted — focused user regression passed
**التاريخ:** 2026-07-31
**الأساس:** Phase 8.6-R1 user-tested stable

## المشكلة بمنطق الشيت

بعد أن أصبح للشيت مالك دورة حياة واحد، ظل ربط تفاعلات المستخدم موجودًا داخل الملف المنسق الكبير `tabulatorTest.js`.

هذا لم يكن عطلًا ظاهرًا، لكنه يجعل إضافة عمود أو طريقة تفاعل مستقبلية أخطر. مثال: لو أضاف المستخدم عمود “القيمة التقديرية”، يجب أن يستخدم نفس طريق الكتابة والأسهم والنسخ واللصق، لا أن ينشئ طريقًا ثانيًا قد ينفذ الأمر مرتين.

## ما تغير

أضيف `wwwroot/js/tabulatorInteractions.js` ليكون مالك ربط التفاعلات التالية:

- Resize وحارس نطاق كليك اليمين.
- بدء وإلغاء وتثبيت تعديل الخلية.
- تنشيط الخلية والنطاق والقائمة.
- تتبع الضغط داخل وخارج الشيت.
- الأسهم والكتابة المباشرة وDelete/Backspace.
- Undo/Redo.
- Copy/Paste على مستوى document.

`tabulatorLifecycle.js` ما زال مسؤولًا عن فصل هذه الأحداث وتنظيف المؤقتات عند تغيير السنة أو مغادرة الصفحة.

## ما لم يتغير

- أعمدة الشيت أو قواعدها.
- طريقة حركة الأسهم.
- Quick mode وText mode.
- Copy/Paste أو History.
- Resize وتثبيت موضع الصف.
- كليك اليمين وإدراج/حذف الصفوف.
- الحفظ والتحقق والتكرارات والصلاحيات.

تم نقل نفس الكتل التنفيذية دون تعديل مقصود في المنطق.

## مثال عملي

1. الموظف يفتح سنة 2026.
2. Interactions يربط مجموعة واحدة من الأسهم والنسخ واللصق والقائمة.
3. الموظف ينتقل إلى 2025.
4. Lifecycle يفصل مجموعة 2026 ويدمر الشيت القديم.
5. Interactions يربط مجموعة واحدة لنسخة 2025.

النتيجة المطلوبة: Ctrl+V ينفذ Paste واحدة ويضيف Undo واحدة، مهما كرر المستخدم تغيير السنة.

## الملفات الرئيسية

- `wwwroot/js/tabulatorInteractions.js` — جديد.
- `wwwroot/js/tabulatorTest.js` — أصبح منسقًا أصغر ويستدعي مالك التفاعل.
- `Components/App.razor` — تحميل الموديول بعد Lifecycle.
- وثائق المشروع وقائمة Regression.

## الفحص الساكن المنفذ

- JavaScript syntax check لكل ملفات `wwwroot/js`.
- مقارنة نصية أثبتت أن كتل التفاعل المنقولة مطابقة للنص السابق.
- واجهة `tabulatorTest` القديمة لم تفقد أي method؛ أضيفت فقط طريقتا الربط.
- كل `document/window/element.addEventListener` الخاصة بالشيت أصبحت داخل Interaction، والتنظيف ظل داخل Lifecycle.
- لا يوجد `*.user` داخل Patch.

## اختبار القبول

استخدم القسم R في `06_REGRESSION_TEST_CHECKLIST.md`. لا تنشئ Tag قبل نجاح الأسهم، Quick/Text editing، Delete، Copy/Paste، Undo/Redo، كليك اليمين، Resize، وتغيير السنة دون تنفيذ مزدوج أو Console errors.
