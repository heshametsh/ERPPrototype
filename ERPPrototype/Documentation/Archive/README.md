# Archive

هذا المجلد يحفظ وثائق وتقارير تاريخية فقط.

لا تستخدم أي ملف هنا لاتخاذ قرار حالي إلا للمقارنة التاريخية.  
المراجع الحالية موجودة في `Documentation/00_DOCUMENTATION_INDEX.md`.

## Why keep old files?

لأن حذف التاريخ يجعلنا نفقد سبب قرارات سابقة. لكن تركه بجانب الوثائق الحالية بدون علامة Archive يسبب تعارضًا.

**Example:**  
نسخة Power Apps محفوظة لمعرفة تاريخ المشروع، لكنها ليست تعليمات لبناء النسخة الحالية.
