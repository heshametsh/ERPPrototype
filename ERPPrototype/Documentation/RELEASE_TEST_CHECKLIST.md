# Release Test Checklist

## 1. Build baseline

- [ ] فك النسخة في مجلد جديد، وليس فوق المشروع الحالي.
- [ ] فتح `ERPPrototype.csproj`.
- [ ] `Build > Clean Solution`.
- [ ] `Build > Rebuild Solution` بدون Errors.
- [ ] تسجيل كل Warnings وعدم تجاهل تحذيرات Nullable أو EF Core.

## 2. Startup and database

- [ ] تشغيل محلي بـ `Ctrl + F5`.
- [ ] التأكد أن الـSeeder لا ينشئ Admin ثانيًا.
- [ ] التأكد أن كل فرع يحتوي الأقسام القياسية الأربعة مرة واحدة.
- [ ] التأكد أن قاعدة البيانات الحالية لم تتغير بنيويًا.

## 3. Authentication

- [ ] تسجيل دخول Admin صحيح.
- [ ] رفض كلمة مرور خاطئة.
- [ ] قفل الحساب بعد 5 محاولات فاشلة.
- [ ] رفض مستخدم `IsActive = false`.
- [ ] إجبار الحساب الجديد على تغيير كلمة المرور.
- [ ] عدم فتح `/admin` لمستخدم Employee.
- [ ] عدم فتح `/work-orders` لمستخدم Admin أو BranchManager.
- [ ] تسجيل الخروج يعيد إلى مسار محلي فقط.

## 4. Admin and fixed accounts

- [ ] إنشاء فرع جديد ينشئ الأقسام الأربعة.
- [ ] منع تكرار اسم الفرع.
- [ ] إنشاء BranchManager واحد فقط للفرع.
- [ ] إنشاء Employee واحد فقط لكل قسم.
- [ ] منع إنشاء حساب ثانٍ حتى لو الحساب الثابت غير نشط.
- [ ] منع Username مكرر.
- [ ] منع Email مكرر.
- [ ] مراجعة قائمة مستخدمي الفرع.

## 5. Work-order scope and permissions

- [ ] Employee يرى قسمه فقط.
- [ ] Employee لا يستطيع قراءة أو تعديل قسم آخر عبر تغيير URL أو طلب مباشر.
- [ ] تحميل كل سنة يعرض `DepartmentId + WorkYear` فقط.
- [ ] تغيير Assignment Date ينقل السجل إلى سنة التاريخ عند الحفظ.
- [ ] حذف Assignment Date من سجل موجود يبقيه في سنة الشيت الحالية.

## 6. Validation and data integrity

- [ ] رقم أمر العمل 9 أرقام ASCII بعد تحويل الأرقام العربية والفارسية.
- [ ] نوع العمل 3 أرقام ASCII.
- [ ] منع تكرار `(WorkOrderNumber + WorkTypeCode)` على مستوى الشركة.
- [ ] رسالة التكرار تعرض السنة، والقسم عندما يكون مختلفًا.
- [ ] Basket من القائمة المعتمدة فقط.
- [ ] Notes بحد أقصى 1000 حرف.
- [ ] فشل الحفظ لا يترك جزءًا من العملية محفوظًا.

## 7. Concurrency and deletion

- [ ] فتح نفس السجل في تبويبين.
- [ ] حفظ التبويب الأول.
- [ ] رفض حفظ التبويب الثاني برسالة RowVersion واضحة.
- [ ] حذف سجل ثم Undo داخل الجلسة.
- [ ] الحذف الصلب يعمل فقط في الحالة الحالية غير المرتبطة.

## 8. Delta save and grid behavior

- [ ] تعديل خلية واحدة يحفظ صفًا واحدًا فقط.
- [ ] إضافة صف ترجع Id وRowVersion جديدين.
- [ ] حذف صف يرسل Id المحذوف فقط.
- [ ] نقل سنة لا يعيد تحميل الشيت كاملًا بعد الحفظ.
- [ ] Undo/Redo بعد الحفظ يعملان للحالات المدعومة.
- [ ] Copy/Paste مع Excel.
- [ ] الفلترة والبحث وتحديد النطاقات.

## 9. Performance

- [ ] قياس SQL Load من Logs.
- [ ] قياس وقت إنشاء Tabulator من Logs.
- [ ] 3,000 صف: وقت الفتح.
- [ ] 3,000 صف: نعومة التمرير.
- [ ] 3,000 صف: البحث والفلترة والتحرير والحفظ.
- [ ] 10,000 صف داخل شيت واحد.
- [ ] مراقبة Memory من Browser Task Manager.
- [ ] بقاء الصفحة مفتوحة 60 دقيقة.
- [ ] انقطاع الشبكة وعودة الاتصال.

## 10. Production deployment

- [ ] Connection String من إعدادات Azure، لا من المصدر.
- [ ] `AllowedHosts` محدد باسم النطاق الحقيقي.
- [ ] تطبيق Migrations بخطة نشر منفصلة ونسخة احتياطية.
- [ ] HSTS وHTTPS يعملان.
- [ ] مراجعة Logs وApplication Insights.
- [ ] اختبار شبكة شركة الكهرباء.
- [ ] فحص الحزم للثغرات باستخدام أدوات .NET/NuGet الحالية.
- [ ] مراجعة مستقلة للأمان والصلاحيات قبل إدخال بيانات حقيقية.
