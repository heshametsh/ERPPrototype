ERP Grid Shootout — Gate 0

This lab does not touch the production Work Orders page. It exists only to eliminate weak grid engines before any migration work.

Same dataset, same machine, same Chrome profile, same zoom, same torture cycle. A candidate that fails selection correctness, fast-scroll rendering, clipboard, RTL, or resize stability is eliminated.

The competitor pages use pinned public CDN builds only for this isolated evaluation. If a winner is selected, its final assets will be vendored locally before production/offline work.

Current baseline: Tabulator 6.5.0

Control group. Stock engine only, without the ERP custom patches. This tells us whether a failure belongs to Tabulator itself or our integration.
