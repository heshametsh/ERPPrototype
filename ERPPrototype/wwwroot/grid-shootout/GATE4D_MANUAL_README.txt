RevoGrid Community — ERP Gate 4D MANUAL — 100,000 rows

Purpose:
- The user performs the actual interaction.
- The harness only observes, validates, and reports PASS/FAIL.

Manual flow:
1) Edit Notes manually, Ctrl+Z, Ctrl+Y, Save, Ctrl+Z, Ctrl+Y.
2) Harness copies 5,000 values only; user selects Notes and presses Ctrl+V, Ctrl+Z, Ctrl+Y.
3) User presses Enter on a prepared readonly Remaining Amount cell.
4) Harness prepares a 1,000-row range; user presses Delete, then Ctrl+Z/Ctrl+Y/Ctrl+Z.
5) User clicks Add Custom Column, then Ctrl+Z/Ctrl+Y.
6) User selects Basket and manually toggles Split/Full four times.
7) User switches RTL, selects Basket, and manually scrolls hard.
8) User changes browser zoom manually 100 -> 90 -> 80 -> 67 -> 100.

No Work Orders production files are modified.
