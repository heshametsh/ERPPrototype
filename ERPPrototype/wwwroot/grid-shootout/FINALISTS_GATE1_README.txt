ERP Grid Finalists — Gate 1 Simplified
=======================================

المرشحان
- RevoGrid 4.25.2
- Univer 0.25.1

الرابط
http://localhost:5265/grid-shootout/finalists.html

الخطوات المختصرة
1) ابدأ بـ 10,000 صف.
2) افتح المحرك واضغط: تشغيل الاختبارات الآلية.
3) بعد انتهائها: حدد Basket واسحب Scroll فوق/تحت بعنف 20 مرة ثم افحص التحديد.
4) جرّب Zoom 100 -> 90 -> 67 -> 100 + نصف الشاشة + RTL.
5) اختبر Clipboard: تجهيز اللصق -> نسخ 1000x6 -> Ctrl+V -> فحص اللصق.
6) صدّر النتيجة JSON وأرسلها.

لا نرفع إلى 50k أو 100k قبل نجاح 10k وظيفيًا.
